# ArogyaSetu Frontend

React + Vite + Tailwind CSS frontend prototype for ArogyaSetu, a connected public-healthcare coordination platform.

## Included flows
- Landing page with Login/Register modal
- PHC dashboard, patient search, referral creation and teleconsultation
- District hospital dashboard, doctors/slots and emergency desk
- Patient dashboard, appointments, nearby facilities and ABHA-linked medical history
- ASHA dashboard, overdue referral follow-up, maternal/chronic care, area view and patient registration

## Run locally

```bash
npm install
npm run dev
```

For a production check:

```bash
npm run build
```

The application currently uses mock data and frontend-only interactions. Backend/API integration can be added without changing the route structure.
